# Support

Brewlet is an open source project provided under the terms of the
[MIT License](LICENSE).

## Questions, bugs, and feature requests

Search the [documentation](https://brewlet.sh/docs/) and existing
[GitHub issues](https://github.com/microsoft/brewlet/issues) first. If the
problem has not already been reported, open an issue using the appropriate
template and include enough information to reproduce or understand it.

Support is provided through the community on a best-effort basis. Opening an
issue does not create a Microsoft support obligation or service-level
commitment.

## Security issues

Do not disclose suspected vulnerabilities in a public issue. Follow the private
reporting process in [SECURITY.md](SECURITY.md).
