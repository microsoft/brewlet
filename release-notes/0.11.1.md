> [!WARNING]
> **0.x releases are not stable.** Every 0.x version is a beta: APIs, artifact
> formats, CRDs and behavior can change incompatibly between releases. Do not
> use 0.x in production. General availability (GA) will be **Brewlet 1.0.0**.

- **Registry reliability:** Runtime image pulls using configured registry hosts
  now time out when responses stall, with additional installation timing logs.
- **Local Kubernetes tutorial and demo:** A local OCI registry replaces manual
  image imports, and runtime rotation has more reliable feedback and guards.
- **Java documentation:** A new Maven plugin reference and expanded Spring Boot
  and Quarkus guidance cover packaging, launch descriptors and configuration.
- **Validation:** The complete Kubernetes E2E matrix runs weekly and on demand
  on native amd64 and arm64.

Transitions between different beta releases remain unsupported without reviewed
evidence; see the release distribution and recovery guide.
