> [!WARNING]
> **0.x releases are not stable.** Every 0.x version is a beta: APIs, artifact
> formats, CRDs and behavior can change incompatibly between releases. Do not
> use 0.x in production. General availability (GA) will be **Brewlet 1.0.0**.

- **Per-container runtimes:** Set `runtime-image.brewlet.sh/<container>` on a
  Pod template to select a RuntimeImage for that container. A Pod can use
  several runtimes and run ordinary OCI sidecars without a selection. This
  replaces the Pod-wide `brewlet.sh/runtime-image` annotation.
- **Simpler application packaging:** Package libraries with the application
  payload instead of composing managed dependency layers. The CLI accepts
  `source:destination` layer mappings and infers their roles.
- **Kubernetes guides:** New documentation covers Argo Rollouts and compares
  Brewlet with native Kubernetes image volumes.
