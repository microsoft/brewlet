> [!WARNING]
> **0.x releases are not stable.** Every 0.x version is a beta: APIs, artifact
> formats, CRDs and behavior can change incompatibly between releases. Do not
> use 0.x in production. General availability (GA) will be **Brewlet 1.0.0**.

- **Runtime launch:** Runtime image `ENTRYPOINT` now prefixes the application
  process, with runtime `CMD` inherited when no launch or Pod command is set.
  Pod `command` and `args` override application launch fields without replacing
  the runtime entrypoint. Republish runtime generations installed by earlier
  releases so nodes record the image's launch configuration.
- **Launch descriptors:** `process.entrypoint` is now `process.command`, and
  the runtime allowlist has been removed. Update descriptors and rebuild
  application artifacts for the new contract.
- **Maven plugin:** The new `build` goal produces a local OCI layout; `push`
  publishes an existing layout without rebuilding it. Update Maven invocations
  that previously used `push` for both steps.
- **Dashboard:** Authentication is retained across page reloads.

Transitions between different beta releases remain unsupported without reviewed
evidence; see the release distribution and recovery guide.
