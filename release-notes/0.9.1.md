> formats, CRDs and behavior can break, change incompatibly or pivot again

> will be **Brewlet 1.0.0**.

Brewlet 0.9.1 is a patch release on the 0.9.0 line.

- **containerd 2.x activation fix:** containerd 2.x (for example AKS Ubuntu
  24.04 with containerd 2.3) migrates an on-disk version 2 config and reports
  its effective `containerd config dump` as version 4. The node provisioner
  now accepts version 4, which keeps the version 3 CRI runtime and image
  plugin layout. In 0.9.0 every activation on these nodes rolled back.
- **Safer containerd restarts:** repeated activation and rollback restarts
  could trip systemd's `start-limit-hit`, leaving containerd stopped and the
  node `NotReady`. The provisioner now runs `systemctl reset-failed
  containerd` before every containerd restart it issues.

If 0.9.0 left nodes `NotReady` with `start-limit-hit`, upgrade to 0.9.1, then
run `systemctl reset-failed containerd && systemctl start containerd` on the
affected nodes (or reimage them).
