> formats, CRDs and behavior can break, change incompatibly or pivot again
> between releases. Do not use 0.x in production. General availability (GA)
> will be **Brewlet 1.0.0**.

Brewlet 0.10.0 improves command-line operations and the path from installation
to managing runtimes and dependencies.

- **NodeProfile management:** `brewlet k8s profile` can list, inspect, create
  and delete profiles, and add or remove runtime offerings. Mutating commands
  support `--dry-run`, and deletion reports affected nodes and workloads.
- **Readable CLI results:** result commands print text by default, including
  when piped or redirected. Use `-o json` or `--output json` for machine-readable
  stdout. Result files remain compact JSON.
- **Managed-dependency walkthrough:** a new Log4j example shows how to publish
  approved dependency bundles and update a composed application without
  rebuilding its application artifact.
- **Getting started and documentation:** improved installation guidance,
  navigation and Java demo documentation, plus local Kubernetes tutorial
  fixes for Apple silicon and clearer runtime-rotation steps.
- **Dependency refresh:** updated runtime, Maven and documentation dependencies
  and CI tooling.
