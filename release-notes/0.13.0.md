> [!WARNING]
> **0.x releases are not stable.** Every 0.x version is a beta: APIs, artifact
> formats, CRDs and behavior can change incompatibly between releases. Do not
> use 0.x in production. General availability (GA) will be **Brewlet 1.0.0**.

- **Node worker networking:** Workers now use the Pod network and cluster DNS
  rather than host networking. Allow Pod egress to DNS, the Kubernetes API and
  runtime registries; registries reachable only on the node's loopback address
  are no longer reachable from the worker. Worker metrics endpoints use Pod IPs.
- **Helm configuration:** The chart validates all documented values and rejects
  unknown keys, invalid types, and other constraints that were previously not
  checked by its schema. Some values may also have been rejected later by the
  templates, API server or operator.
- **Node activation:** The provisioner queries the containerd CRI socket
  directly, removing the requirement for `crictl` on the host.
- **Linux scheduling:** Helm-managed operator, admission, dashboard and
  uninstall Pods select Linux nodes. NodeProfiles must still target Linux-only
  node pools.

Transitions between different beta releases remain unsupported without reviewed
evidence; see the release distribution and recovery guide.
