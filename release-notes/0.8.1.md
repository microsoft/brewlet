> formats, CRDs and behavior can break, change incompatibly or pivot again
> between releases. Do not use 0.x in production. General availability (GA)
> will be **Brewlet 1.0.0**.

Brewlet 0.8.1 is a patch release on the 0.8.0 line.

- **macOS `brewlet build` fix:** the producer now ignores the host-local
  `com.apple.provenance` and `com.apple.quarantine` extended attributes that
  macOS attaches (and re-applies) to files created by downloaded apps. These
  attributes are never written into layers. Any other extended attribute is
  still rejected with `LayerPathViolation`, now naming the attribute.
