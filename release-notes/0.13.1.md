> [!WARNING]
> **0.x releases are not stable.** Every 0.x version is a beta: APIs, artifact
> formats, CRDs and behavior can change incompatibly between releases. Do not
> use 0.x in production. General availability (GA) will be **Brewlet 1.0.0**.

- **Runtime platform validation:** Cache successful validation proofs and
  limit platform metadata reads to relevant images. This reduces repeated
  registry requests that could exhaust Docker Hub's quota and cause nodes to
  lose runtime readiness. Cold starts and worker restarts can still require
  registry requests.
- **Documentation:** The documentation site distinguishes the latest release
  from unreleased changes on main.

Transitions between different beta releases remain unsupported without reviewed
evidence; see the release distribution and recovery guide.
