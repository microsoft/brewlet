> [!WARNING]
> **0.x releases are not stable.** Every 0.x version is a beta: APIs, artifact
> formats, CRDs and behavior can change incompatibly between releases. Do not
> use 0.x in production. General availability (GA) will be **Brewlet 1.0.0**.

- **Runtime platform validation:** Node workers cache successful validation
  for the runtime identity and required platforms and avoid fetching unrelated
  image metadata on every reconciliation. This reduces registry requests that
  could exhaust rate limits and cause runtime readiness failures. Validation
  runs again after a worker restart.
- **Documentation versions:** The documentation site now distinguishes the
  latest release from development on `main`, with a version selector and an
  unreleased-changes banner on development pages.

Transitions between different beta releases remain unsupported without reviewed
evidence; see the release distribution and recovery guide.
