NOTICES AND INFORMATION
Do Not Translate or Localize

Brewlet's own source license is LICENSE.txt (MIT). Third-party notices are
scoped to the dependencies actually redistributed by each built artifact.
This index is not an aggregated third-party license or a compliance opinion.

CLI build
    make build places brewlet, LICENSE.txt and generated NOTICE.txt in bin/.
    go run ./scripts/notice --output bin/NOTICE.txt ./cmd/brewlet
    Keep both text files beside the binary when distributing it. This branch
    does not implement release archive publishing.

Control container (operator and admission in one image)
    kubernetes/Dockerfile generates /NOTICE.txt for both linked executables
    and copies Brewlet's license to /LICENSE.txt.
    go run ./scripts/notice --goos linux --goarch amd64 \
      --output bin/control-notice.txt ./kubernetes/cmd/operator ./kubernetes/cmd/admission

Worker container (brewlet-node and containerd shim)
    provisioner/Dockerfile generates /NOTICE.txt for both linked executables
    and copies Brewlet's license to /LICENSE.txt. This image does not download
    or redistribute the old standalone kubectl, ctr or crictl tool set.
    go run ./scripts/notice --goos linux --goarch amd64 \
      --output bin/worker-notice.txt ./cmd/brewlet-node ./shim/cmd/containerd-shim-brewlet-v2

Maven plugin
    mvn -B -f maven-plugin/pom.xml verify generates META-INF/NOTICE.txt from
    the actual resolved runtime JAR license and notice resources and packages
    META-INF/LICENSE.txt. Provided and test dependencies are excluded.
    Legal resources are generated in target/classes, not checked-in snapshots.

Static website/documentation preview
    site/scripts/build.py combines site/NOTICE.txt with installed documentation
    dependency license texts. The source of truth is the preview build in
    .github/workflows/site-pages.yml; it does not publish production Pages.

Helm chart
    The chart embeds configuration, not third-party executable code.

Container base-image license and attribution files remain in their original
filesystem locations; generated Go notices do not replace them. No additional
Microsoft container legal notice is currently supplied by this source tree.
Confirm any additional distribution-policy requirement with the release owner
before publishing; do not assume the old nonexistent notice was packaged.

See docs/third-party-notices.md for generation, verification and limitations.
The ordinary contracts job in .github/workflows/v2-ci.yml runs make legal-check.
